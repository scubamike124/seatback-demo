# Seatback: synthetic demo (static replay)

This is a self-contained replay of one Seatback result. **It uses synthetic (invented) data.** It does not show live Qloo results, and nothing on this page has been validated against airline viewing data.

- Open `index.html` in any browser. No server, no account, no API key.
- The page makes no external requests. A small inline script switches the tabs between panels that are already on the page; the example buttons for the other two routes, "Build slate" and the CSV buttons only show a notice, because this replay holds one stored result (Minneapolis to Orlando). To try other routes or your own catalogue, run the app from the repository.
- Full project (public, Apache-2.0): https://github.com/scubamike124/seatback
